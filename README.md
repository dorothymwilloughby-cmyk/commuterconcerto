# Commuter Concerto

A Doramora internet experiment that turns Phoenix traffic into music.

## Doramora experiment conventions

- Keep the experiment itself visually distinct.
- Use the Doramora experiment shell: warm cream, near-black ink, bright accent palette, chunky outlined UI, playful microcopy.
- Include a `doramora*` brand mark, an `AN INTERNET EXPERIMENT` label, and a route back to `/experiments`.
- Preserve accessibility and mobile usability when styling.
- Netlify production remains the publishing target.

## Workflow

GitHub is the source of truth for this experiment. Changes should be committed here first, then deployed to Netlify.
